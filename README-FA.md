# ICYGEM Website

نسخه انگلیسی سایت ICYGEM. برای اجرای سریع، فایل `index.html` را در مرورگر باز کنید.

## فایل‌ها
- `index.html` صفحه اصلی و محتوای انگلیسی
- `styles.css` استایل، واکنش‌گرایی و جلوه‌های بصری
- `script.js` ستاره‌های متحرک و پنل‌های لینک SoundCloud/YouTube
- `assets/` آیکون و تصویر معرفی شبکه‌های اجتماعی

## لینک‌ها
- SoundCloud: https://on.soundcloud.com/maDo3tNgAXLrQLBBHP
- YouTube: https://youtube.com/@icygemm?si=W-091MKSS5qzBIuQ

برای انتشار روی دامنه، می‌توانید فایل‌ها را در سرویس میزبانی static مانند Cloudflare Pages قرار دهید.
